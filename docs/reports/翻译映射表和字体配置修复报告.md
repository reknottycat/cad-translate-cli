# CAD翻译工具 - 翻译映射表和字体配置修复报告

## 问题描述

用户在使用CAD翻译工具时遇到了两个主要问题：

1. **翻译映射表加载失败**：日志显示"翻译映射表为空或加载失败"，提示需要存在`extracted_texts_for_translation.xlsx`等文件
2. **字体配置不生效**：GUI中选择的字体为Times New Roman，但实际使用的是Arial

## 问题分析

### 1. 翻译映射表问题
- **根本原因**：文件名不匹配
  - 提取文本脚本生成的文件名：`extracted_texts.xlsx`
  - 回填脚本查找的文件名：`extracted_texts_for_translation.xlsx`
- **影响范围**：回填功能完全无法工作

### 2. 字体配置问题
- **根本原因**：GUI中的字体设置函数为空实现
  - GUI中的`set_font()`函数只有`pass`语句
  - 回填脚本中硬编码了`font_name = "Arial"`
- **影响范围**：用户无法通过GUI更改翻译文本的字体

## 修复方案

### 1. 修复翻译文件名匹配问题

**修改文件**：`回填.py`

**修改内容**：
```python
# 修改前
translation_files = ['extracted_texts_for_translation.xlsx', '3.xlsx', 'translation.xlsx']

# 修改后
translation_files = ['extracted_texts.xlsx', '3.xlsx', 'translation.xlsx']
```

### 2. 实现GUI字体配置功能

**修改文件**：`gui.py`

**修改内容**：
```python
# 修改前
def set_font(font):
    """设置字体（简化版）"""
    pass

# 修改后
def set_font(font):
    """设置字体"""
    import re
    script_path = Path("回填.py")
    if not script_path.exists():
        return False
        
    try:
        with open(script_path, 'r', encoding='utf-8') as f:
            content = f.read()
        
        # 替换字体设置行
        pattern = r'font_name = "[^"]+"(\s*# 默认字体)'
        replacement = f'font_name = "{font}"\\1'
        new_content = re.sub(pattern, replacement, content)
        
        # 如果没有找到带注释的行，尝试替换不带注释的行
        if new_content == content:
            pattern = r'font_name = "[^"]+"'
            replacement = f'font_name = "{font}"'
            new_content = re.sub(pattern, replacement, content)
        
        if new_content != content:
            with open(script_path, 'w', encoding='utf-8') as f:
                f.write(new_content)
            return True
    except Exception as e:
        print(f"设置字体失败: {e}")
    return False
```

### 3. 优化回填脚本字体设置

**修改文件**：`回填.py`

**修改内容**：
```python
# 修改前
font_name = "Arial"  # 默认字体，可直接修改此行来更改默认字体

# 修改后
font_name = "Arial"  # 默认字体
```
