## 💡 优化建议

### 🎯 字体选择建议
- **当前状态**: 使用Times New Roman，适合英文显示
- **推荐改进**: 考虑使用Microsoft YaHei以获得更好的中俄文显示效果
- **操作方法**: 运行 `python font_config.py` 选择字体

### 📐 字号调整建议
- **当前设置**: 减少4个单位，翻译文本相对较小
- **适用场景**: 适合文本密集的图纸，避免翻译文本过大影响布局
- **调整建议**: 
  - 如果翻译文本太小难以阅读，可将 `font_size_reduction` 改为 2-3
  - 如果翻译文本太大影响布局，可保持当前设置或增加到 5-6

### 🔄 翻译模式说明
- **当前模式**: 替换原文 (replace_mode = True)
- **效果**: 直接用俄文替换中文，保持图纸整洁
- **替代方案**: 设置为False可在原文下方添加翻译（双语显示）

## 🛠️ 配置修改方法

### 快速修改字体
```bash
python font_config.py
```

### 手动修改配置
编辑 `回填.py` 文件中的以下参数：
```python
# 第295行附近
font_name = "Times New Roman"  # 修改字体
replace_mode = True            # 修改翻译模式
font_size_reduction = 4        # 修改字号减少量
```
