# CAD翻译工具 - 使用说明

## 📦 打包信息

- **可执行文件**: `dist\CAD翻译工具.exe`
- **文件大小**: 约 822 MB
- **打包时间**: 2025年8月26日
- **Python版本**: 3.12
- **打包工具**: PyInstaller 6.15.0

## 🚀 快速开始

### 方法一：直接运行exe文件
1. 双击 `dist\CAD翻译工具.exe` 启动程序
2. 首次启动可能需要10-30秒，请耐心等待
3. 程序界面出现后即可正常使用

### 方法二：使用启动脚本（开发环境）
- 运行 `start_gui.bat` 或 `start_gui.ps1`
- 适用于有Python环境的情况

## 💡 功能说明

### 主要功能
1. **DWG转换**: 将DWG文件转换为DXF格式
2. **文本提取**: 从CAD文件中提取文本内容到Excel
3. **文本回填**: 将翻译后的文本回填到CAD文件
4. **自动处理**: 一键完成提取→翻译→回填流程

### 支持的文件格式
- **输入**: DWG, DXF
- **输出**: DXF, Excel (.xlsx)

## ⚙️ 系统要求

### 最低配置
- **操作系统**: Windows 10/11 (64位)
- **内存**: 4GB RAM
- **硬盘空间**: 2GB 可用空间
- **显示器**: 1024x768 分辨率

### 推荐配置
- **操作系统**: Windows 11 (64位)
- **内存**: 8GB RAM 或更多
- **硬盘空间**: 5GB 可用空间
- **显示器**: 1920x1080 分辨率

## 🔧 故障排除

### 常见问题

#### 1. 程序启动缓慢
- **原因**: 首次启动需要解压和初始化
- **解决**: 耐心等待，后续启动会更快

#### 2. 缺少依赖库错误
- **现象**: 提示找不到某些模块
- **解决**: 重新下载完整的exe文件

#### 3. CAD文件处理失败
- **检查**: 确保CAD文件未损坏
- **检查**: 文件路径不包含特殊字符
- **检查**: 有足够的磁盘空间

#### 4. Excel文件无法打开
- **检查**: 确保安装了Excel或兼容软件
- **检查**: 文件未被其他程序占用

### 性能优化建议

1. **关闭不必要的程序**: 释放内存资源
2. **使用SSD硬盘**: 提高文件读写速度
3. **定期清理临时文件**: 保持系统整洁
4. **批量处理**: 一次处理多个文件更高效
